## 어려웠던 점 3가지와 해결
1. 화면 크기에 따라 영화 카드가 한 열 두열 네열로 바뀌게 하는게 어려웠는데 미디어 퀴리를 사용하여 해결했습니다.
2. 이미지 주소를 입력했는데 화면에 제대로 안 나오는 경우가 있었습니다. 이미지 주소와 경로를 다시 확인하고 정상적으로 표시되게 수정했습니다.
3. 영화 포스터와 상세 정보를 보기 좋게 좌우로 배치하는게 어려웠는데 css 그리드를 사용해서 화면 크기에 따라 배치가 바뀌도록 설정하여 해결했다
